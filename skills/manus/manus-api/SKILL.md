# Manus API

## Overview
Programmable task/project management via OpenAPI v1/v2.

## Capabilities
- Create/List/Delete tasks and projects
- Webhooks for real-time updates
- OAuth2 Open Apps for third-party integration
- Connectors: Gmail, Google Calendar, Notion, Slack
- Data Integrations: SimilarWeb

## API Versions
- v1: OAuth-based, file management, webhooks
- v2: ApiKey auth, agents, browser automation, structured output
