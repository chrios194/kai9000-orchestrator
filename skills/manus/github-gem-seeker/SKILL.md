# GitHub Gem Seeker

## When to Use
- Format conversion (video/audio/image/document)
- Media downloading
- File manipulation
- Web scraping/archiving
- Automation scripts
- CLI tools

## Workflow
1. Define the problem (format, source, target)
2. Search GitHub: `topic:<topic> stars:>50 language:<lang>`
3. Evaluate: stars, last commit, license, dependencies
4. Clone and adapt

## Anti-Pattern
Don't write custom code for problems that open-source has already solved.
