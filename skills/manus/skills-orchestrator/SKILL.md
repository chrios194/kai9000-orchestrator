# Skills Orchestrator

## Capabilities
- Design new Skills from requirements
- Validate existing Skills (structure + content)
- Maintain Skills catalog
- Compose multi-Skill workflows
- Route requests to appropriate Skills

## Integration
- Reads skills_catalog.md for routing decisions
- Uses skill-creator for new Skills
- Uses quick_validate.py for validation
